# Список дел

Сервис для управления личными задачами с помощью Python:
- Добавление, поиск, отметка статуса задач,
- 100% тестирование логики через pytest,
- интеграция с GitHub Actions для автоматической проверки кода и тестов.

## Быстрый старт

1. Клонируйте проект:
https://github.com/EvgeniyBabin0/TodoProject.git

2. Установите зависимости
pip install -r requirements.txt

3. Запустите тесты:
pytest

4. Смотрите исходную логику в main.py, тесты — в test_todo.py

## Концепция решения

| Название действия    | Локейшн (URL)   | Тип запроса | Описание запроса и ответа                               |
|----------------------|-----------------|-------------|---------------------------------------------------------|
| Получить все задачи  | `/tasks`          | GET         | Возвращает список всех задач в формате JSON           |
| Создать задачу       | `/tasks`          | POST        | Принимает title, возвращает созданную задачу          |
| Получить задачу по id| `/tasks/{id}`     | GET         | Возвращает задачу с указанным id                      |
| Обновить задачу      | `/tasks/{id}`     | PUT         | Обновляет title или completed, возвращает обновлённую задачу |
| Удалить задачу       | `/tasks/{id}`     | DELETE      | Удаляет задачу, возвращает статус успешного удаления    |

### Классы и структура данных
Класс `Task` -- представляет одну задачу с полями title, completed, created_at.

Класс `TodoList` -- управляет набором задач — добавляет, удаляет, обновляет, сохраняет и загружает задачи из файла.

Разделение на модули для удобства поддержки и расширения.

### Основной функционал 
Добавление задачи.

Пометка задачи как выполненной.

Получение списка всех задач и только невыполненных.

Сохранение/загрузка задач из JSON-файла.

Консольная демонстрация основных возможностей в main.py.

### Тестирование 
Покрытие основных классов и методов юнит-тестами (pytest).

Обработка пограничных случаев (невалидные индексы, отсутствие файла, ошибки форматирования).
